## 四、计划功能（待实现）

### 4.1 Phase 1: MaterialChunk 管道

**目标**：从 `rawText` 自动分块并创建 `MaterialChunk` 记录

| 功能 | 文件 | 说明 |
|------|------|------|
| ChunkingService | `backend/src/modules/material/services/chunking.service.ts` | 文本分块逻辑 |
| 集成到 MaterialProcessor | `backend/src/modules/material/processors/material.processor.ts` | 提取后自动分块 |
| Chunk API | `backend/src/modules/material/material.controller.ts` | `GET /materials/:id/chunks` |

**分块策略**：
- 按语义边界（段落、章节）分块
- 保持上下文连贯
- 单块建议 500-1000 字

### 4.2 Phase 2: Embedding/RAG 集成

**目标**：为每个 chunk 生成向量 embedding，支持 RAG 问答

| 功能 | 文件 | 说明 |
|------|------|------|
| AI Module | `backend/src/modules/ai/ai.module.ts` | AI 模块入口 |
| EmbeddingService | `backend/src/modules/ai/embedding.service.ts` | OpenAI Embeddings API |
| .env 配置 | `OPENAI_API_KEY` | 需要用户配置 |

**技术细节**：
- 模型：`text-embedding-3-small` (1536 维)
- 批处理避免限流
- 向量存储：pgvector 扩展

### 4.3 Phase 3: AI/LLM 服务层

**目标**：提供摘要生成、知识抽取、测验生成、学习计划生成

| 功能 | 文件 | 说明 |
|------|------|------|
| LLMService | `backend/src/modules/ai/llm.service.ts` | OpenAI/Claude 接口 |
| Prompt 模板 | `backend/src/modules/ai/prompts/*.ts` | 各类 AI 提示词 |
| AI Processor | `backend/src/modules/ai/processors/ai.processor.ts` | BullMQ AI 任务 |
| AI Controller | `backend/src/modules/ai/ai.controller.ts` | AI 功能 API |

**AI 功能**：

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 摘要生成 | 为 material/chunk 生成摘要 | P0 |
| 知识单元抽取 | 从 chunks 提取知识点 | P0 |
| 测验生成 | 基于知识点生成测验题 | P0 |
| 学习计划生成 | 生成 7~14 天学习计划 | P0 |
| AI 问答 | 基于资料回答问题（需 RAG） | P1 |
| 错误分析 | 测验错因分析 | P1 |
